# One-minute walkthrough

1. Start a run from the War room. Let the first exchange populate the feed.
2. Show how Scout, Injector, Sentinel and Patch Engineer each contribute a different role.
3. Switch to Red squad, then Blue squad, then an individual agent thread.
4. Return to War room. Choose either outcome on Containment's approval card.
5. Show the scoreboard and findings ledger.
6. Return to the feed and ask the Director to summarize the incident.
7. Toggle the theme or narrow the browser to show mobile behavior.

Explain that the current submission demonstrates the interaction design and Director integration; the security execution layer is the next engineering milestone.
